# AI Job Agent

Cel projektu:

Stworzyć system AI, który automatyzuje proces szukania pracy.

Etapy:

1. Analiza CV
2. Pobieranie ofert pracy
3. Dopasowanie ofert do kandydata
4. ~~Generowanie CV pod ofertę~~ — pominięte, decyzja użytkownika
5. Generowanie listu motywacyjnego
6. Dashboard
7. Półautomatyczne aplikowanie

Projekt tworzony jako portfolio AI Automation.
Kod ma być modułowy i łatwy do rozwijania.
